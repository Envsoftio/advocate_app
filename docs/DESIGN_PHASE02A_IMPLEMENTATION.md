## Implementation

The existing working-PDF reader now opens on **Read**. It identifies the real working revision and source-page count, retains the existing Edit/Annotate/Stamps/Pages/Output tabs, and presents Search, Document bookmarks, Document information and Focused reading using Phase 01 semantic tokens and bundled Inter. Existing OCR, Details, history, Save copy, Print, Index and preparation navigation remain reachable. No new route, processing library, backend, schema or artifact permission has been introduced.

- **Thumbnails:** reuse the existing bounded `PdfThumbnailRail` in ordinary and expanded reading. Remove the duplicate seven-page thumbnail renderer. The shared rail renders actual pages with loading/unavailable feedback, arrow-key navigation, existing revision-checked drag/keyboard reordering and selected-page reveal.
- **Search:** reuse `usePdfSearch` and its actual PDF.js text extraction, cross-run occurrences and transient text highlights. Results now occupy a scrolling side panel instead of taking paper height. Next/previous, Enter/Shift+Enter, result click and Up/Down/Home/End operate on real occurrences. Query/selected occurrence survive panel changes. Empty, unavailable, loading, truncated and extraction-error states remain explicit.
- **Bookmarks:** the panel lists the PDF's embedded outline and this document's existing manual bookmarks. It navigates resolved current-revision destinations; stale manual targets remain disabled and marked for review. Empty/loading/failure states distinguish no entries from a failed lookup. Editing or resolving bookmarks remains in the existing Index & bookmarks workflow.
- **Information:** show persisted title, original filename, working revision/current page count, document date with source/status, OCR processing status and original SHA-256. Do not invent an original page count, verified text status or legally verified signature. Imported-original viewing remains unavailable under the existing API; no decorative version selector was added.
- **Panels and focus:** one reading panel is active at a time and replaces the thumbnail rail. Opening focuses search or Close; Close/Escape returns to the invoker or mounted reader. The original Details visibility/focus behavior remains untouched. The PDF viewport remains mounted, retaining its existing geometry, resize anchoring and revision-scoped position persistence.
- **Focused reading:** temporarily hides reader panels, tools, thumbnails and surrounding navigation, retaining document/revision identity and navigation/zoom controls. It preserves zoom rather than invoking the existing Full screen fit-page behavior. Exit/Escape restores the prior panel, thumbnail preference, expanded/list state and trigger focus. Full screen retains its established behavior. Read entry confirms before discarding an existing unfinished PDF-tool draft.
- **Artifacts:** the working reader continues to use the existing working-copy service and mutation guards. The generated reader retains authenticated range loading, immutable build identity, search/bookmark navigation and no mutation controls, with an explicit “Generated PDF · Read only” label. Original bytes, generated bytes, page-map/index rules and edit/export services are unchanged.
