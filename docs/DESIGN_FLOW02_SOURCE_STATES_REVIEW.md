## API and implementation

- Import now detects PDF pages with image content but no searchable text in the normalized working copy. This sets `needs_ocr` without changing or inferring verification of the imported original.
- OCR accepts optional zero-based `page_index`, validates range and expected working revision, runs only that page on a candidate working copy, and records the selected page in provenance. Other page content and original bytes are preserved. When scanned pages remain, the document stays in `needs_ocr`. An already recognized page is not destructively replaced by this operation.
- The frontend adds the three honest OCR preparation states, a current-page OCR action for unprocessed pages, real job cancellation, scoped batch guard wording, and the focused-reading layout/focus correction. A follow-up aligns 05B, 06C, 07A, 07B and 08A composition with their supplied geometry. Existing document state, build page map and export logic were not changed by the UI follow-up.
- The completion pass adds SQLite schema 25 for revision-bound OCR review and job start time, portable backup version 18 for review records, an OCR confidence inspection endpoint, guarded page rerun, and original print preparation. The arm64 sidecar now bundles the Tesseract executable needed for confidence TSV; the working PDF is never edited by inspection or view rotation.
